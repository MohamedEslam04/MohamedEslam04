## 📦 Open Source

### [@eslamdevui/ui](https://www.npmjs.com/package/@eslamdevui/ui)
A fully accessible, high-performance UI component library for **Vue & Nuxt**, built on Tailwind CSS and Tailwind Variants.

### [vue-directives-kit](https://www.npmjs.com/package/vue-directives-kit)
A collection of Vue 3 custom directives for common interaction patterns and cleaner templates.

### [github/advisory-database #10339](https://github.com/github/advisory-database/pull/10339) — _merged_
Fixed a **GitHub Advisory Database** entry ([GHSA-mrhx-c7xc-m3w5](https://github.com/advisories/GHSA-mrhx-c7xc-m3w5)) for **zod** that shipped with an empty `affected` list — causing scanners to flag every zod version. Traced the fix to zod 4.6.6, corrected the range to `< 4.6.6`, and added the fix PR, release, and issue as references.

### [vercel/next.js #93757](https://github.com/vercel/next.js/issues/93757)
Reported a critical Next.js bug where a single 0-byte file in `.next/cache/images/` permanently poisons the disk-LRU singleton, breaking image optimization for the whole process. Provided root-cause analysis across 3 source files and 4 suggested fixes — plus a [minimal reproduction](https://github.com/MohamedEslam04/next-image-lru-repro).
